Privacy Policy

Effective date: November 14, 2026

This policy describes the personal Windows uploader operated by knowledgeforyoueveryday and this informational website.

Information accessed and used

  • OAuth credentials: Google access and refresh tokens are used to authorize uploads to the selected YouTube channel.
  • Video content and metadata: a locally selected video, title, description, category and visibility setting are sent to YouTube to perform the requested upload.
  • Upload results: the returned video ID and upload response are saved locally to record success and help prevent duplicate uploads.

The current uploader requests only the https://www.googleapis.com/auth/youtube.upload OAuth scope. It does not request Gmail, contacts, watch history or analytics access.

Storage and retention

Credentials, video files and upload receipts are stored on the operator’s computer. The current implementation saves OAuth credentials in a local JSON file; it does not provide additional application-level encryption. They must not be uploaded to a public repository or this website. Local records remain until the operator deletes them.

YouTube stores uploaded videos and associated metadata under its own policies. Deleting a local file or revoking access does not delete an uploaded YouTube video.

Sharing and service providers

The uploader sends credentials and upload data to Google services as needed for authorization and uploading. It does not sell Google user data, use it for advertising, or send it to AI model providers. This uploader has no operator-hosted backend storing Google credentials or videos.

Video generation is a separate workflow. Any scripts or media sent to model, voice or stock-media providers through MoneyPrinterTurbo are subject to the operator’s configuration and those providers’ policies. This policy must be updated before future features change the handling of Google user data.

Google API data use

MoneyPrinter-Automation’s use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including its Limited Use requirements. Google user data is not used to train generalized AI or machine-learning models.

Your controls and deletion

You may revoke the tool’s access from your Google Account connections settings. You can then delete the local authorization JSON file and upload receipts. To remove an uploaded video, delete it separately in YouTube Studio. Revoked or expired credentials require a new authorization before uploads resume.

This website

This static website has no forms, analytics scripts, advertising or application cookies. GitHub Pages hosts the website and may process technical request data under the GitHub Privacy Statement. If you contact the operator by email, your address and message are used to respond.

Changes and contact

This page will be updated if the tool’s data practices change. Questions or data-related requests can be sent to knowledge.for.you.everyday@gmail.com.
