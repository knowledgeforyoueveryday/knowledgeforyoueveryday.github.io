Personal desktop utility

MoneyPrinter-Automation

A personal Windows tool for uploading locally created videos to the operator’s own YouTube channel using the YouTube Data API.

This website provides information about the tool. It does not offer account sign-in, collect video uploads, or run the desktop application.

What the tool does

The operator selects a local video and authorizes a Google account through Google’s OAuth consent flow. The tool sends the video, title, description and selected visibility to YouTube, and saves the returned video ID locally. The current upload test uses private visibility.

The tool accompanies a local installation of the open-source MoneyPrinterTurbo video generator. Automated topic selection, scheduled generation and publishing are planned extensions; this page describes the current uploader.

Google access

The tool requests youtube.upload access to upload videos on behalf of the authorized user. Google handles authentication; the tool does not ask for or store the user’s Google password. OAuth credentials are saved on the operator’s Windows computer so subsequent uploads can refresh access when permitted.

Who operates it

This personal integration is maintained by the GitHub account knowledgeforyoueveryday. It is not an official Google product and is not the official MoneyPrinterTurbo project.
